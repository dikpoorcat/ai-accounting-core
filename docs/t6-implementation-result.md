## 实际效果

继续使用原有 Vue 应用、五页入口和已验收共同查询。公司和期间选择集中到页头，侧栏保留五页导航；手机保留底部五页入口。公司切换等新 context 返回后决定同月、默认月或空态，并显示回退说明。刷新会校验更新后的可选月份；旧公司的响应、错误、收尾和定位不得覆盖新选择。页面筛选保留在 URL，模块切换只携带公司与月份。

| 页面 | 已实现的信息层级与使用路径 |
| --- | --- |
| 经营简报 | 四卡先回答本月账面盈亏、月末账面资金、月末待收和待付；桌面四列、手机两列。随后是经营说明或正式事实概览、分类提示、待收待付来源、业务凭证、用工及资产构成，核算与来源依据放在后部。正式业务、后来清偿、外部办理及文件集合可精确定位展开；无凭证的正式结果仍可达。 |
| 资金 | 先看账面余额、账户分布及全月收支，再选账户和明细。账面变动与银行原文采用短行、行内展开；后页账户可以继续加载并保留精确名称。账面/基金凭证入口取实际入账期间，银行原始行不冒充凭证。历史未知候选在本页保留原因和精确追溯。 |
| 员工 | 全领域指标在准备区前；列表固定结构，手机改为带标签的两列信息。展开先看款项概况与来源期工资/劳务，再看构成、实际扣税、申报和代发依据。各员工来源续页与劳务集合独立恢复。 |
| 资产 | 核心账面价值与本月变动优先；资产卡片、项目投入、变动记录有就近导航。取得与付款保持来源/批次范围，未证明候选直接可展开核对，不跳到不存在的差异区。资产与项目分页独立。 |
| 财务报表 | 季度状态、下一步和三表摘要先于长表及准备资料。各月历史/当前跟进默认折叠，月份、关键状态、未知及分组问题摘要仍可见；完整三表保留局部横向滚动。沿用原有预览、资料选择、生成与下载绑定。 |

共用准备区明确写“所选期间相关的当前跟进”，说明全公司范围、未按页面筛选，只包含所选期间业务相关后来事项。每个非空问题组展示准确问题条数和首条内容，展开保留全部已返回问题及独立来源；只有汇总的文件/外部组进入已有分页明细。未发布数量不链接到仅含正式结果的集合。待更正业务单独定位，不能把组级身份套给别的问题。

未知金额显示“暂无法确定”，管理资料缺少显示“未提供”。金额已知但结果不完整时仍显示警示。首页四卡直接消费完整历史字段，待收注明包括预付款待冲抵，不解释为未来到期现金；未从已加载行累加金额、推断状态或重新计算会计含义。

续页与详情失败就地重试，保留同版本成功内容；独立集合有各自请求和错误状态。文件集合游标失效只先重读文件；业务版本也改变时才按业务作用范围重读。凭证详情重试原目标，来源明细重试原游标。经营简报增量加载保留当前位置，不再强制跳回区段顶部。
