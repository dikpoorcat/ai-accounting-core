## 1. 最终交付范围

- 产品创建的新企业默认启用期间控制；迁移发现的旧企业保持未启用，未来必须走独立历史迁移流程。
- 会计期间按公历自然月逐月显式生成。首月可从任意过去月份开始，后续只能连续生成下一月；不能生成 Asia/Shanghai 当前月之后的月份。
- 启用期控后，未生成月份、已关闭月份及未来日期均禁止正式入账。所有企业的正式入账日均不得晚于 Asia/Shanghai 当前日期。
- 月结采用只读预览、规范 JSON、SHA-256 计算哈希和复算确认；确认保存完整凭证、分录、账户发生额和来源事件快照。
- 状态机固定为 `generated_open -> closed`，不支持反结账。关闭月错误只能在后续已生成开放月通过关联冲正和原专用工作流重记。
- 系统重算草稿、凭证完整性、固定资产折旧、无形资产摊销、借款计息和工资批次；银行、往来、工资法定事项、税务及资产借款清单另由六项显式人工复核冻结。
- 零凭证月份不会自动跳过，但在六项人工复核全真、确认说明和证据齐全时允许显式关闭。
- 历史税期继续保留原税务范围；更正产生的调整凭证使用显式 `adjustment_posting_date` 记入后续开放会计月。
- 通用预收、履约、退款和退货新增规范依赖边，父事件必须在有效子事件全部逆序冲正后才能冲正。

## 2. 稳定公共契约

新增四个严格参数的本地 STDIO MCP 工具，仓库共公开 38 个工具：

- `finance_generate_accounting_period`
- `finance_preview_accounting_period_close`
- `finance_confirm_accounting_period_close`
- `finance_get_accounting_periods`

所有请求均为类型化对象且 `additionalProperties: false`，不接受科目、借贷行、余额或调用方声称的系统检查结果。缺少会改变处理的事实返回 `needs_information`；同幂等键同载荷回放，同键换载荷返回 `ACCOUNTING_PERIOD_IDEMPOTENCY_PAYLOAD_MISMATCH`。

生成和关闭动作冻结企业、月份、规则版本、官方来源、证据、确认人文本、说明、规范请求哈希及结果。确认人文本只构成审计声明，不代表真实身份、RBAC、电子签名或四眼审批。

## 3. 持久化与 PostgreSQL 提交点

线性迁移 `0012_accounting_period_close` 位于 `0011_intangible_borrowings` 之后，新增或强化：

- `AccountingPeriodCalendar`、`AccountingPeriod` 和逐月生成动作；
- `AccountingPeriodAction`、动作证据、不可变关闭快照及全部来源快照；
- `BusinessEventDependency` 通用业务父子依赖；
- `TaxPeriod.adjustment_posting_date` 税务范围与会计入账日分离。

迁移在首个 DDL 前拒绝无法证明的新期间历史或污染依赖，失败时 revision 和存量不变；空库及可证明历史链支持 `0011 -> 0012 -> 0011 -> 0012` 和 `base -> head -> base -> head` 往返。

PostgreSQL 17 提交点实际验收覆盖：

- 期间必须是唯一、完整、连续的自然月，期控启用和起始日不可原地回退；
- 生成使用企业生成锁再取月份锁；直接 SQL 与服务使用同一锁序，不能并发跳月；
- 正式业务写入先取税期企业锁，再取会计月份锁；月结使用相同顺序，避免锁序反转；
- close-vs-post、close-vs-close、工资预览及直接 SQL 并发最多一方按先后线性化成功，失败方取得稳定领域错误，外层提交不泄漏裸数据库异常；
- 关闭来源全集、逐凭证和分录快照、账户汇总、人工复核、规则、前期哈希和 SHA-256 均由数据库独立重算；
- 固定资产、无形资产和借款按截至关闭月的全部应有叶重算，已处置或退役资产的历史漏提不能被排除；
- 关闭快照、动作、证据、依赖边及正式事实不可更新、删除或跨企业重绑；
- 关闭月不得事后形成草稿业务事件、草稿凭证或未完成工资批次。

## 4. 关闭后更正与税务协同

后续开放月的关联冲正不修改旧凭证、旧事件内容或旧关闭快照。关闭哈希保存关闭时点的事件状态快照，不依赖以后可变的 `posted -> reversed` 生命周期，因此合法后续冲正不会使历史关闭哈希漂移。

税期确认预览和确认均验证 `adjustment_posting_date` 命中已生成开放会计月且不在未来；税务归属范围与凭证入账日分别进入计算哈希、正式事实和数据库提交点。税期来源锁、工资累计链、开放项及各专用模块的逆序依赖不能被月结或后续月更正绕过。
