# 看板与内核对齐说明

本说明约定五页看板与现有 SQLite 内核的查询、关联和展示口径；不重新记账、不修改已冻结的核算结果，也不以页面投影改变数据库结构。

## 已有资料直接复用

历史页面缺少姓名或人员编号时，按同一身份复用已有展示档案、收款人资料及个税导入身份，提供实际采用的资料来源；存在冲突则提示核对。负责人不必为了让页面显示名称重新录入已经存在的资料。

实际申报可以发生在工资所属期之后，页面按工资来源关联，分别列出税期和登记月份，后来补充的资料有明确提示。期初薪酬分别展示工资来源期、启账月及正式应付组成；奖金和期初接续不会被提示补充常规工资申报。入离职日期优先用于判断所选月份的在册情况，当前停用状态不能倒推过去已经离职。上述管理信息不会改变工资、税额或历史凭证。

只有确实没有依据的资料才显示“未提供”。按月确认的取得月份、扣缴起点等保留月份精度，不补造日期。居民身份、购价拆分、付款到期日等原来恒空且不符合当前事实结构的栏目已移除或替换。

## 五页采用的展示口径

| 页面 | 本轮调整 |
| --- | --- |
| 经营简报 | 业务确认金额、凭证合计和实际资金分别展示；交易方按对应业务关系关联，批次人员不复制到每条分录；冲正说明对原业务的更正，按原凭证号区分。用工成本包含独立奖金拆分，资本化劳务另列。备用金只展示实际支出或退款，不生成余额、额度或结清关系；工资混合付款明确拆分应付净薪和备用金支出。 |
| 资金 | 对外流入流出剔除账户互转，账户明细仍保留转入转出；银行与支付平台之间的转款恒为内部划转，备用金支出和退款按实际资金方向列示。银行流水区分未提供、部分覆盖、完整覆盖及待复核。货币基金按确认成本列示，申赎确认和真实收付款分别展示。 |
| 员工 | 工资、奖金、社保公积金、规则计算税额、实际扣税及申报分别查看。按工资来源期展示公司付款、代付转债、非现金抵销、尚未清偿及代发保留差额；劳务区分费用化与资本化，不按付款比例推算毛额或税额。 |
| 资产 | 在用资产、待启用固定及无形资产、尚未转出的项目成本一并展示并核对。多笔收付款和核销按来源展开；整批验收展示批次债权人及结算，项目形成资产展示成本来源，不推定逐卡付款分摊。处置确认与款项收回分开。 |
| 财务报表 | 已有月份不等于已关账；准备事项保留业务和凭证定位。预览采用的补充资料沿用到导出；任务完成且文件校验通过后才能下载，失效结果明确提示并支持重新生成。 |

## 刷新、分页与金额

页面版本、独立集合、游标、未知候选及当前跟进口径见 [有界看板查询](bounded-dashboard-queries.md)。

五页使用同一公司和月份选择。切换时取消旧请求、清空旧数据；刷新同时更新可选月份，等待中的旧响应不能覆盖新选择。

汇总由后端完整计算，长明细按页加载。继续加载时校验数据版本；期间数据变化则重新加载，避免旧页和新页混在一起。页面说明已加载范围，局部筛选不会冒充全量筛选。

浏览器接口传输整数分字符串，前端使用 `BigInt` 精确显示。CLI/MCP 继续保持原有类型合同；页面不重新计算会计结果，也不将缺少的银行资料当作零流水。

实际页面响应统一从 Python 类型模型生成 JSON Schema、TypeScript 和 Ajv 校验器；请求通过生成校验和公司、月份、筛选及快照关联检查后才使用。分页只保留一份 `items/page`，原始任务结果不进入浏览器任务列表。后端响应不符合合同是程序错误，不转成负责人补资料。

清偿事件明确显示“关系已确认／关系尚待确认”，同时保留未知金额和问题。本月发生额与期末余额的未映射科目分别提示；本月非零而期末为零时仍保留本月提示，金额按现有正负号格式显示为元。

外部事项分别显示实际办理与账务核对，允许“已申报，账务尚待核对”；季度税务与财报独立。文件任务显示稳定错误说明，不把本机异常转成负责人缺少业务资料；任务生成、真实付款和对外提交分别表达。

## 同版月度核对

经营简报的月度核对区读取 `dashboard_close_review`。AI 先生成单月关账预览，负责人在页面核对，再由 AI 请求本机密码窗口并执行单月关账。页面不增加准备、批准或关账按钮，也不增加调用入口记录或近期变更列表。

核对内容与正式关账共用 `preview_digest`，包括业务分类、实际资金、凭证与试算、资料覆盖及精确采用依据。摘要、详情分页、密码窗口和关账固定使用同版内容；新预览替代旧预览或数据版本变化时，旧内容失效，不静默跳到新版本。服务重启后开放月需重新准备。

已关账月份读取冻结核对内容及原版来源。被后续关账覆盖的空月只说明覆盖状态，不补造独立批准或冻结内容。未准备与已失效分别提示由 AI 重新预览，不补造负责人确认。公司或月份切换立即清空旧核对状态。

详情按冻结排序和分块摘要读取，普通分页只装载命中块，完整核验检查全部来源。原始文件名用于阅读，内部编号、版本和摘要放入技术详情。
