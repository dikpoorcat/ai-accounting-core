# 货币基金的成本与实际资金

本模块只接收明确按小企业会计准则归为短期投资的货币基金：能随时变现，且持有意图不超过一年。产品名、平台余额和预估收益率不能替代这项分类或账面成本依据。现有真实资料中的余利宝交易仍是待核对候选，本模块没有认定或写入任何真实交易。

依据为财政部《[小企业会计准则](https://kjs.mof.gov.cn/zhengcefabu/201111/P020111118325852319878.pdf)》第六、八条（2013年起施行），及其[科目和报表附录](https://kjs.mof.gov.cn/zhengcefabu/201111/P020111118325852734144.pdf)中的1101、5111和现金流量表第8、11行。取得成本包含购买价款及相关税费；本模块要求确认价款不含已宣告未发放的分配收益。赎回结算净款减去有据账面成本计入投资收益，负数为损失。

| 类型化事实 | 必要依据 | 发布结果 |
| --- | --- | --- |
| `money_fund_subscription` | 具体基金、结算交易方、短期分类、购买价款、取得税费（零也明确）、成本依据及证据 | 短期投资成本及向结算方应付的申购款 |
| `money_fund_redemption` | 同一具体基金、结算交易方、结算净款及每个申购或期初来源分配的本次成本 | 减少来源成本，确认应收结算净款和投资损益 |
| `opening_money_fund` | 原成本批次身份、期初成本、短期分类、证据 | 通过完整平衡的期初包进入1101期初余额，不产生当期收入费用或现金流 |

实际银行付出、到账继续使用不可变的 `payment`，其 allocation 指向申购或赎回事实的 `primary` obligation。来源事实与付款可一起交给普通 `preview/confirm` 原子发布，也可先确认投资再在真实收付款发生后核销。核销按实际日期和金额记录，交易方和应收应付方向必须一致；不从投资确认月份补造付款日期。申购成本对应同一结算方应付总额，若实际费用另付其他交易方或包含待分配收益，需要另行明确业务事实，不能套入本模板。

赎回的全部实际净到账列现金流量表第8行；赎回价差虽然计入利润表第20行“投资收益”，不因此拆出现金流量表第9行。第9行指实际分配的股利、利润、利息，与出售短期投资所得价款不同。申购实际付款列第11行；期初和未收未付确认都不产生现金流。资产负债表第2行反映剩余1101成本。

成本分配引用正式申购或已采用的期初明细，显式限定基金和期间；所有当前已确认赎回（含尚未发布者）合计不能超出来源成本。多次、部分赎回可逐项消耗来源，全部成本消耗后余额归零。缺少分类、成本、净结算金额或证据返回 `needs_information`。月精度足以确认投资；如果提供实际确认日，必须与所属月一致，且已知的日先后关系也会校验。

范围不包括市价重估、推算或自动再投资收益、复杂金融资产、自动判定投资收益税务处理；相应事实不能靠本模块默认填补。公共调用不接收科目或借贷行。开放期更正、关账后关联更正、幂等、来源封存、实际资金不可变和投影重建均走统一内核。

验证命令：`.tmp-kernel-venv/Scripts/python.exe -m pytest tests/kernel/test_investments.py -q`。覆盖申购/部分和多批次赎回、正负及零回款、真实银行对账、季度冻结报表、期初无现金流、收益更正与实际回款保留、容量与缺项阻断，以及增量投影和重建一致。
