## 1. 最终交付范围

无形资产一期完成：

- 外购、已可供使用、可单独识别且不含土地权利的单项资产取得；
- 银行现付或供应商挂账，分别精确匹配银行流水或生成受控应付开放项；
- 从可供使用当月开始、自然月连续、整数分最后一期闭合的直线摊销；
- 自然月末、收入/赔偿/税费/残料四项均显式为零的报废；
- 资产卡片、规范事实、凭证、证据、累计摊销、账面价值和完整历史查询；
- 报废、最新摊销、取得的依赖逆序冲正，取得冲正后编号不复用。

借款一期完成：

- 中国持牌金融机构、人民币、单次全额放款、固定利率、合同单利、到期一次还本且无需资本化的合同；
- 严格递增并以到期日结束的应付息日清单，`actual_360` 或 `actual_365` 日计数；
- `[period_start, period_end)` 实际天数、固定本地 `Decimal` 上下文、`ROUND_HALF_UP` 整分利息；
- 计息预览与哈希确认、唯一关联付息、到期日全额还本；
- 合同、有效本金、应计/已付/未付利息、规范事实、凭证、证据和冲正历史查询；
- 还本、付息、最新计息、放款的依赖逆序冲正，放款冲正后编号不复用。

两个模块都没有开放科目、借贷方向或自由分录输入。旧粗粒度事件和全部内部规范事件通过 `finance_record_event` 提交时只返回专用工作流错误。

## 2. 稳定公共契约

- 新增 11 个严格参数的专用 MCP 工具；仓库共公开 34 个本地 STDIO 工具。
- 所有新请求及其嵌套对象均为 `additionalProperties: false`，公开 Schema 不含 `entries`、科目代码/角色或借贷金额字段。
- 缺少会改变处理的事实返回 `needs_information`；事实完整但越出一期范围才返回稳定 `rejected` 错误。
- 金额及派生金额均限制在有符号 64 位整数分范围；利率只接受十进制字符串或 `Decimal`，不得使用二进制浮点。
- 借款年利率必须在 `(0, 100]` 且最多六位小数，正式事实、哈希和 `Numeric(9,6)` 规范行统一保存六位。
- 写请求按命令和规范载荷计算 SHA-256；同键同载荷回放，同键换载荷返回模块专用 `IDEMPOTENCY_PAYLOAD_MISMATCH`。
- 正式事件冻结规则版本、财政部官方来源、已验证事实、证据、计算、固定角色模板、依赖和解释轨迹。
- 正式凭证和规范事实不可原地修改；更正只创建关联反向凭证并保留完整历史。

## 3. 持久化与提交点验收

当时的线性迁移 `0011_intangible_borrowings` 在 `0010_tax_determinism` 之后新增六张规范业务表和迁移账户所有权表，并为新企业及既有企业安全配置十个固定系统角色。

迁移在第一个 0011 DDL 前检查账户冲突和不兼容历史；既有同代码兼容账户只绑定角色，不覆盖其他事实。降级只有在不存在任何规范事实、新事件或已引用的迁移创建账户时才允许，并按 `created` / `bound` 所有权精确删除或恢复。

PostgreSQL 17 提交点实际验收覆盖：

- 七类正式事件的规范 facts、规则、凭证角色和金额、证据、银行匹配或开放项必须精确一致；
- supplier / lender 的组织、类型、名称和外部编号与正式事实一致；
- 资产摊销连续、不重复、不超额，报废后不可再摊销且必须先完成当月摊销；
- 借款计息按应付息日连续，数据库独立重算利息和完整计算哈希；
- 付息日位于计息期末至合同到期日闭区间，到期还本前必须连续计息至到期且全部利息已付；
- 规范行、正式事件、凭证、证据、交易对手、银行流水和账户的直接 SQL 篡改在提交时拒绝；
- 同资产/借款并发进入同一根锁域，后提交者不能形成重复摊销、计息、付息、报废或还本；
- 通用 Python `FinanceService` 和 MCP 冲正入口都不能绕过专用下游依赖检查。

## 4. 独立负向审计

执行包完成后，独立验收逐项复现并关闭了下列缺口：

- 借款利息不得受进程全局 Decimal 精度或 trap 影响；
- 利率不得因 SQLite / PostgreSQL 回读精度变化而漂移；
- 计算哈希必须包含放款事件、合同、应付息日及全部有效前序计息事件；
- 成功幂等回放必须保留凭证 ID 和编号，非正式裁决并发不得泄漏唯一约束异常；
- 交易对手 ID 与名称/外部编号不得冻结相互矛盾的事实；
- 必填文本不得只含空白，公开供应商 Schema 必须发布实际长度边界；
- 成本合计、利息和生命周期不得越过数据库整数或日期可表示范围；
- 根事件冲正后的查询余额归零、状态为 `reversed`，但历史链继续保留；
- 付息不得晚于合同到期日，避免进入一期排除的展期或罚息判断；
- 直接实例化通用服务也不能越过无形资产或借款的逆序冲正门禁。

最终核心层复验为 `36 passed`，未发现剩余 P0、P1 或 P2。
