# 代码收口

## 口令

```text
代码收口
代码收口：最近3个提交
代码收口：b4e59b8
代码收口：只审查
```

## 提示词

对指定提交进行代码收口，未指定范围时默认最近一次提交。先区分运行代码、测试、生成物、历史合同、临时工具和文档，不能只凭新增行数判断好坏。

检查重复实现、无用代码、职责混杂、一次性工具进入运行层、历史适配扩散、生成物重复、测试依赖临时环境，以及重复读取、核验、装载和缓存处理。发现一处问题，沿调用链排查同类问题，列清实际问题和修改范围，再集中修复。

清理必须贯通相关字段、查询、调用方、缓存、依赖、测试、生成器和文档，不能只删表面内容。生成物从定义或生成器解决；历史合同保留精确来源和指纹。共同职责适当集中，不为统一代码硬造框架。

技术缺陷自行处理；涉及业务用法、功能删减或体验变化，提出具体影响和建议交给我决定。保留信任链、业务能力、金额精度、历史语义及必要核验，不操作真实资料或现有服务，不覆盖其他任务的改动。

修改收敛后成组验证，保留业务断言、损坏拒绝和必要的工作量检查。没有新变化、失败或风险，不重复大套测试。未验证就明确写未验证，不能靠删除断言、降低门槛或减少功能宣称优化完成。

最后简明报告：清理了什么、为什么、验证结果、仍未解决什么。更新必要文档，不堆过程说明。默认实施技术修正；带“只审查”时不修改。未经明确指令，不提交或推送 Git。
