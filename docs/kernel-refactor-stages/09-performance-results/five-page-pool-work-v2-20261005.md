## 根因与同类排查

原私有测量脚本包装 `Store.connection`，正常看板却经过 `_snapshot_connection` 直接借用专用连接池。脚本没有进入计量连接，首个页面断言失败；原脚本又在断言之后才保存观测，导致失败原件没有页面记录。不能据此认为页面没有读取或业务对照通过。

检查公共计量器、当前及历史读取、五页、普通Engine、包／MCP、HTTP插桩与历史辅助脚本后，确认该具名来源的适配问题。直连及当时仍经过 `Store.connection` 的历史来源保留原适用范围；动态导入和覆盖脚本没有仅凭文字相似宣布已验证。完整静态矩阵随原件归档。

修正只在私有v2脚本中包装实际连接提供器；QueryReads仍收到原始专用连接，事务保护、精确类型、授权器、借还和生产路径不变。公共计量器继续记录执行步数、返回值、结果传输及解码。逐页先保存完整响应和工作量，再检查断言，失败不再丢失已有观测。没有修改生产代码或固定源码。
