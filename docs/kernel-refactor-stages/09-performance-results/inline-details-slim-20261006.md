# 两处整行展开与详情精简验证

## 实现范围

待收待付移除独立详情列和按钮，整行点击、Enter／空格展开、收起，并以小箭头提示。每个区域仅展开一行，没有业务身份的行不提供展开提示。分类、公司、月份或快照变化时收起详情；内部操作不切换整行。原行保留对象、事项、状态及所选月余额，原金额与实际收付等辅助摘要移入展开区。

展开只展示新增信息：待收待付删除重复分类、对象事项标题、状态徽标和历史剩余金额卡；本月发生删除重复本次事项卡。本次发生金额、日期、说明和状态仍由原行精确表达，零值、负值与超大整数分保持，未知金额显示待核对。历史行之后发生的业务撤回保留中性提示，不因去重丢失后续事实。用途／备注仅按完整文本去重，角色、其他人员、资产和账户保持；款项仍按义务 key 精确关联，不按姓名或金额匹配。

整笔业务逐项进度与后续变化保持独立口径，实发工资、个税、社保不相互覆盖。未知详情或匹配失败保留列表明确金额并提示核对。预付款区分退款与冲抵，处理完成称已处理完毕。未结清和部分收付为琥珀色，结清为绿色，更正、撤回与纯历史为中性色；核对与超额结算另有提示，后续面板取消固定绿色底色。相关收付说明缩短，分页有续页时只显示已加载／总数与按钮，读取完成后省略重复提示。

业务详情合同保持7，未修改公共接口、数据库结构或依赖。已删除专用分类属性、行辅助摘要计算、详情重复卡及对应样式；金额、身份、展示档案、义务和相关记录仍服务其他入口、精确拆解与核验，后端字段、查询与缓存没有可独立删去的孤立用途。通用详情入口保留原布局。
