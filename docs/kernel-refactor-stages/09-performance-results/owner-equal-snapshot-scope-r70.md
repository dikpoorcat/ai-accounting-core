# 同一快照的相等清偿范围

## 根因和排查范围

先读目标月历史清偿，再读当前清偿时，如果没有目标月之后的发生额，两种口径可共用已核验汇总。原 `_scope` 先再次构造冻结根的全部分组、期间计数和目标月金额，再判断能否复用；这些新对象随后被丢弃。反过来先读当前口径时已有提前复用分支，因此两种顺序的成本不同。

这不是取消历史读取，也不代表所有历史／当前口径都相等。后续真实收付款、更正或未知清偿必须保留不同结果。

| 位置和调用方 | 处理决定 |
| --- | --- |
| `settlement_freeze._scope`；简报待收待付、员工工资未付、资产付款范围、核心清偿查询 | 在公共范围构造处修复，不分别修改页面。完整开放尾部核验先完成，确认能复用后直接返回；不能复用才构造新的汇总。 |
| 资金页／上下文 | 当前该页面的资金与上下文读取不直接进入此范围，不据此宣称提速。 |
| 报表清偿位置、工作清单的清偿汇总 | 共用此函数，保持截止期和未知金额语义；最终受影响组合验证待进行。 |
| 无托管读取、CLI／MCP 独立读取、未来发生额使口径分离 | 保持各自范围构造及核验，不新增跨请求缓存。 |
| 关账、完整核验、修复、备份恢复 | 完整冻结投影检查仍独立核验权威来源，未改写源或修复逻辑。最终发行包验证未进行。 |
| 固定 v1 历史读取 | 独立版本读取文件不修改，不把当前优化回写历史规则。 |

## 修改与验证
