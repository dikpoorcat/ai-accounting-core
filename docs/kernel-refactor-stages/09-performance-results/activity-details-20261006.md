## 展示与读取边界

业务行继续原位展开，按本次事项、整笔业务款项进度、相关收付阅读。本次金额、状态、日期和说明直接绑定选中的发生记录，冲正保留负值并说明原业务更正；未知金额显示待核对。整笔业务当前结果金额、入账月及核算解释退出这个入口。员工、往来方、资产和账户分别表达，已有管理资料明确为业务补充说明。

进度逐项区分实发工资、个税、社保等款项，不累加不同款项的剩余金额。历史进度注明截至所选月末，后续按义务 key 对应并只展示发生变化的款项；没有对应最新款项时保持待核对，不按名字或金额匹配，不将缺项视为结清。预付款区分已冲抵、尚未冲抵和已退回。下方整笔业务相关收付保留用途、月份、处理方式、原处理更正以及分页。
