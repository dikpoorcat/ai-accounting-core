# 资金按业务行展开与详情精简验证

## 实现范围

资金明细“按业务”移除独立入口，按资金行 `id` 整行点击、Enter／空格展开或收起，同一区域一次展开一行，没有业务身份的行不提示展开。原行保留日期、事项、对象、方向与准确资金金额；更正仅在方向说明“更正原业务”，保留带符号金额并使用中性色。详情放在行下方，占满清单宽度，内部操作不切换整行。

资金专用详情直接使用生成的 `FundMovement` 上下文，只补充新增完整摘要、用途、备注和按角色表达的关联对象。只消除完全一致的文案，侧栏当前账户按实体身份排除，同名其他账户和不同角色保留。接口已经返回的本业务自身义务逐项展示所选月末进度，后续仅按义务key列出实际变化；付款没有返回原业务余额时省略该区域，不判断结清，不增加原业务查询。退款与冲抵分别表达，未知金额不显示为零，整批款项不分摊。相关款项处理保留月份、用途、方式与准确金额，核对中的记录仍保留已知金额。

复用合同7、同一详情接口及既有自动续页，每页20条，展开才读取，同范围重开复用。切账户、公司、月份、快照或按流水时收起；收起取消续页，范围失效取消请求并拒绝迟到响应。普通同快照刷新不重发详情，切页面模块不暂停已经展开的详情续读。其他入口保留各自布局。删除资金明细未使用的旧预览及独立操作列样式；通用金额、历史查询、义务关联及相关字段仍供其他入口或核验使用，没有本入口独占的后端字段、预加载或缓存需要删除。

实施基线为开始时干净工作区 `d3aed9b`。未修改公共接口、生成响应格式、数据库结构或真实业务数据，没有新增依赖；本次按用户要求提交，不推送。

## 功能与构建

- 前端回归251项通过；生成合同检查、合同样例、类型检查、普通及release构建、差异空白检查通过。项目没有独立lint命令。
- 新增资金详情单元／渲染回归覆盖准确金额、大整数、无义务与未知分类、逐项工资和税款、预付款冲抵与退款、超额结算、原处理更正、历史与最新进度、精确文本去重和账户身份排除。按不同资金行身份分别展开，同一业务的另一条记录不能替换本行金额。
- release与现有5173入口的浏览器回归均通过。真实库只读验证首次展开及缓存；7个合成资金场景覆盖部分支付、同业务再次支付、同名账户互转两侧、退款、更正及未知分类大金额。320、375、768、1440px明暗主题共8种布局通过全宽、自然换行和溢出检查；琥珀色未结清、绿色已结清、中性色更正均核验。截图仅保存合成内容。
- 首次展开1个请求，首次失败重试1个，随后自动续页失败1个、重试1个，最终21条。重开已读详情、收起、普通同快照刷新均不增加详情请求；读完不显示重复完成提示，最后一条记录底线为0。
- 账户、月份、公司、快照和按流水切换收起；详情重试不收起整行。展开详情切到概览仍能完成既有续读；收起时取消续页，迟到响应不能追加，重开沿原游标继续。新快照拒绝延迟首屏响应，不自动补发详情。
- 共享待收待付、本月发生的浏览器回归通过；10个页面模块自动续页、筛选、失败重试和4页取消保护通过。凭证悬停、聚焦及保存版本的本地精确定位通过，没有额外详情或简报请求。全部有效浏览器回归脚本错误为0。
