## 截图抽查与老板用法

现有候选 harness 仅在 375px 保存截图：共 12 张，已逐张用 `view_image` 查看。选择包括五页默认截图 `brief.png`、`funds.png`、`employees.png`、`assets.png`、`reports.png`；四页命中详情截图 `brief-business-detail.png`、`funds-business-detail.png`、`employees-business-detail.png`、`assets-business-detail.png`；三张完整报表截图 `report-statement-1.png` 至 `report-statement-3.png`。

375px 的页面采用纵向摘要卡片和清单，资金与报表大额负数仍在卡片范围内，明细保留全量计数与继续查看入口。资金展示账面余额、收付款及业务对象；员工呈现工资与发放状态；资产呈现成本和折旧；未关账报表明确待相关月份结账后下载。抽查可辨识部分未发现技术折叠区或内部哈希、技术编号。业务名称、期间、金额和状态使用简体中文，未见要求老板处理核算来源或技术诊断的入口。

320px 仅有本轮实际 DOM 布局校验，没有保存截图，不能称为 320px 视觉抽查。员工历史已实际点击并通过四视口 DOM 校验；没有单独历史截图，375px 员工详情长图保留了展开后的页面状态。长页截图经图像查看器缩放后，微小明细文字不能逐字辨认；技术检查只匹配 harness 定义的标题关键词，不能据此宣称全部正文已做技术字段穷举扫描。

详情和完整报表全页长图中，固定顶栏、底导航会出现在页面中途并覆盖部分行或标题，图中亦保留点击后的焦点提示。现有检查器没有检查所有固定元素的纵向遮挡，本轮未单独保存滚动位置截图，不能证明纵向滚动时所有内容均无遮挡，也不能仅凭全页截图判定此现象是产品缺陷。本轮没有擅自修复或修改截图。
