# 员工月末未付薪酬：工资与个人劳务合并

## 范围与口径

员工概览使用短标题“截至月末未付薪酬”。金额合计截至所选月末各月份工资、奖金、期初净工资及个人劳务净报酬，包含资本化劳务，减去当时已发生的付款、代付及抵销；不计入代扣税、公司社保公积金或代付后新增的对付款人应付。历史数字不受以后付款、更正或员工筛选、定位、分页影响。

原员工汇总和个人明细的 `outstanding_net_fen` 仍为工资口径。员工合同由9升至10，仅在全公司摘要增加 `outstanding_remuneration_fen`；任一组成项未知时合计为未知，概览显示“暂无法确定”及“AI 会计核对中”。净工资和劳务由后端整数分汇总，前端仍使用 `BigInt` 精确展示。当前没有类型化期初个人劳务入口，普通期初其他应付款不能猜测为劳务。本轮不增加业务入口、缓存、投影表、通用组件或请求。

## 同类排查与实现

| 触发条件与位置 | 核查依据 | 处理决定 |
| --- | --- | --- |
| 员工概览只显示工资未付 | 工资已有全部历史及期初净额；当月劳务列表有期间和分页限制 | 复用工资摘要，增加独立全公司劳务净报酬汇总，不从明细累加 |
| 现有往来分类不能供本卡片直接相加 | 劳务分类还含个税，资本化劳务在其他分类；通用资产负债位置开放路径先聚合全部义务再筛账号 | 依据类型化劳务计算器产生的净报酬账号224104，先限定来源键再聚合对应清偿 |
| 冻结月份已有可信群组 | 工资已经取得同一月份的已核清偿范围 | 复用现有范围，按应付及净报酬账号过滤群组，无逐来源正文组装 |
| 无冻结及开放尾部完整性 | 期间出版、清偿封印和源摘要仍须核验 | 保留既有核验，核验增长成本单列，不宣称完整成本固定 |
| 未知及大金额 | 命中义务的来源、付款、其他清偿未知使剩余未知；SQLite溢出可能报错或提升浮点数 | 保留未知；拒绝整数溢出及浮点数结果，最终范围校验 |

两项小函数位于 `settlement_projection.py` 和 `settlement_freeze.py`，调用只接入员工看板。既有固定历史读取实现未改写。前端只调整概览字段、短标签和说明，个人劳务明细保持独立。
