# 看板读取模型调整方案（已批准）

## 调整原因

五页内容及交互全部保留。旧普通刷新反复读取历史待收待付状态、核对来源并重建对象与事项分组；已有冻结摘要保存完整金额，却缺少看板需要的分组、成员和顺序。同快照复用和局部SQL优化不足以解决整页组装成本，因此改用事务内生产、独立认证的读取模型。

## 已批准的结构与边界

读取模型生产简报、资金、员工、资产的已注册月份响应和续页块，以及看板季度报表。资产active、认证筛选、简报分组与成员、精确凭证已接通；独立Reports、文件预览和下载入口继续承担原职责。

| 内容 | 作用 |
| --- | --- |
| 完整摘要 | 保存全范围金额、数量、未知及异常，明确公司、期间、规则版本和实际发布范围。 |
| 对象与事项分组 | 保存正式对象、类别、组金额、状态和精确成员数；没有正式对象的业务仍独立表达。 |
| 分块成员目录 | 保存精确来源、采用关系和固定块摘要；普通分页只装载命中块和对应原文。 |
| 独立生产记录 | 发布、关账或明确维护操作提交读取根，认证整份读取内容；不能只在投影旁保存自算checksum。 |

模型只决定如何读取已有业务，不决定付款资格、事实修订或会计采用。公司账户来自明确身份；工资、资产成员、跨月清偿、更正、无影响复核和未知金额保留既有语义。名称和拼音排序沿当前明确档案口径，不用冻结旧名称代替当前名称。

正式写入在同一事务内更新已注册月份读取内容，失败一起回滚。页面不自动回填或修复，不以旧模型替代新状态。`rebuild_dashboard_read_model`是明确维护入口。公司新增3表、1索引、2触发器；前向调整接受精确来源和目标合同，目录与公司均保持draft／0，不替换真实库、身份或运行入口。

## 已批准的核验行为

普通命中读取与独立完整核验具有不同范围：正常页面可以在完整摘要和命中来源有效时返回；未命中历史原文的物理损坏由完整核验发现。

每次请求重新认证读取根、完整摘要、命中块、实际采用及返回来源。摘要损坏、块损坏、缺失成员、采用不符和命中原文损坏立即拒绝。成功证明仅在同一owned快照内复用，不跨请求缓存。完整核验、关账、修复、备份和恢复继续从权威事实及结果独立重建比较，不能拿读取模型验证自己。

损坏测试分别证明全范围aggregate、实际raw hit及独立完整核验的职责，不能以普通页面未访问某原文推导它已核验，也不能由页面成功推导关账或备份通过。固定历史decoder及整文件source-hash合同保持原文，必要冻结全目录比较保留。

## 当前实现与生命周期

当前采用明确temporal basis及UI content v2，旧receipt不改写。资金全部流水与完整员工目录的筛选谓词纳入认证；简报group／native member块、精确凭证目录及同快照顺序索引接通。LoadedModel建立只读key／page／collection索引，同一owned快照内focused与overview共享成功完整根证明；每个命中页的哈希和实际来源仍核。非默认筛选可能解码较大的派生命中块，brief tail还会读取首块认证collection_version，不宣称只解码20条或成本恒定。

新月份只由真实typed fact、publication.posting、inventory和close写事务注册，不扫描全表或由普通读取补建。日期变化按temporal basis的实际业务适用范围处理；旧UI v1、构建及业务epochs不匹配仍stale，沿原路径读取或由写入／显式重建生产。隔离registry、固定历史和旧draft不通过副作用生成当前UI。

除已核同日、未被业务引用evidence的窄复用外，一般业务写入仍重建全部已注册月份。根、集合keys、收据审计descriptors和页面认证成本随范围增长；同批多月收据存在重复解析，必要pre／post current认证保留，尚未跨写phase复用。一般write的大样本成本未量化，快刷新不能证明写入达标。

UI blob回收保留所有不可变commit、descriptor、audit、request和parent chain。每批替换前认证，结束时认证所有current根及页，包括stale current；仅回收未被任何current引用的UI blob，不执行VACUUM。旧build current按原字节及固定envelope认证，当前build的native／content version错误仍拒绝；未来model-envelope迁移尚未实现。

生产与独立完整重建的嵌套作用域按公司、连接和快照隔离，proof退出后恢复。同连接不能提升权限，不同连接仅接受current owned-selector快照，固定历史v1规则不得流入当前writer，guard不能绕过。独立完整核验在同一只读事务内复用全部适用源成功核验后的解析结果，保留lease、total_changes、query_only及语义比较，不混用固定v1 decoder。

## 验收边界与证据

当前验收未完成。已通过的固定来源默认页结果只证明其样本与实际页面范围，不能扩大为所有规模、复杂交互、一般写入或跨日性能通过。SQL同类排查中，固定历史合同风险及另一类缺索引问题仍保留，不能宣称全部成本已解决。

源码固定、模型生产、前后统一统计、回归与真实浏览器结果、原失败、备份／前向调整终态及未验范围只在[集中结果](dashboard-500ms-20261010.md)维护；阶段状态见[第9阶段](../09-performance-and-release.md)。真实资料、身份和5173保留，没有真实业务写入、正式冻结或Git提交。
