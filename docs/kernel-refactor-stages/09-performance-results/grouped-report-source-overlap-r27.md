# 报表首次来源核验与少量交集

固定 r26、主 48 月，真实 HTTP 季度报表默认 `preparation=deferred`。本轮没有修改生产。通过公共授权、服务 dispatch 和真实请求插桩，避免把测试生成器保留的大量 Python 对象造成的 CPU 开销算到常驻服务。后台合成建库仍在运行，所有耗时仅用于定位。

| 范围 | 实际装载和交集 | 判断 |
| --- | --- | --- |
| 年初、期末往来 | 年初返回 1,801 个 party 汇总，期末返回 2,401 个；截止期不同 | 两次核算承担不同余额口径，不是重复请求 |
| 开放月第一批贡献 | 938 份贡献，1,382 条来源绑定归并为 939 个计算；先前同快照没有 anchored 或 decoded 成功证明 | 主要开销是首次读取与核验，不能直接省去 |
| 随后现金流／利润贡献 | 请求 1,003 份，937 份命中已有贡献；实际新增 66 份。其 117 条来源绑定对应 116 个计算，与前一批有 50 个计算交集 | 已有贡献缓存确实生效。另加整份贡献缓存没有依据；50 个共同上游的重复字节核验只占小范围，尚无独立净收益或损坏 AB，不改生产 |
| 后续普通来源读取 | 另有 1 个计算与 anchored 字节证明相交，但要求返回解码内容 | 两者证明和返回职责不同，不能把没有解码结果的字节证明冒充普通结果缓存 |

公开报表、季度页面和准备检查共用当前报表计算；原始字节核验仍经 `QueryReads`，范围限于同一只读事务。完整核验、关账、维修、备份／恢复和固定 v1 保留独立权威来源检查，本轮不把当前页的交集结论外推为这些路径已经无重复。

原始有效记录：[来源范围与 CPU 定位](report-http-scope-r27-r4.json.gz)、[13 次 HTTP 结果](report-http-scope-r27-r4-responses.json.gz)。首轮仪表丢失函数签名且未取得错误正文，后两轮在嵌套 cProfile 处失败；它们是测试仪表失败，不是页面正常样本。部分 JSON 和脚本仍在 `.tmp`，失败及修订见[仪表记录](http-report-scope-r27-instrumentation.json)。第四轮只在外层 party 范围启用一个 profiler，13 次 HTTP 均成功；各调用包含关系不能相加。

当前结论：原先怀疑的两批贡献大面积重复已经由命中数据否定；少量共同上游的重复原文读取仍未完成收益验证。120 月、其他详情和异常回退的交集尚未验证。
