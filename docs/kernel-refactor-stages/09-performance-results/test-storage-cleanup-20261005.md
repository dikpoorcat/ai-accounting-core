## 根因与范围

历史测试反复产生完整数据库副本，结束后没有及时退役。最近一次十年样本复制又在目标WAL模式下产生14.44GB的WAL及3.21GB的未完成主文件，耗尽剩余空间。该复制进程已停止；它没有完成内容核验，不是可用样本。失败日志保留，未生成的成功回执不补造。

先核对构造、复制、分叉及中断记录，再确定可退役范围，不按名称中的`old`、`release`、`backup`批量认定无用。清理只涉及明确`.tmp`子目录内的合成SQLite文件、sidecar及合成备份ZIP；未递归删除目录，未跟随reparse point，未触及真实资料和5173服务。完整路径、大小及修改时间先全部核对，保留记录在删除前后分别复验。

当前七个draft性能样本、全部对照源码快照、最新9ac开发包、原始性能与失败记录、证据体积和边界样本保留。`data`、真实备份、负责人身份和当前运行服务不操作。

`rebuild`来源未核实，保留；`.tmp-local-distribution`中的重定位验证目录混有资料与备份，本次保留。其他尚未逐项确认的大目录不写成无用或已排除。清理后`.tmp`由清理前盘点的319.393 GiB降至123.595 GiB；剩余内容包含当前样本、验证资料、源码及未核实资源，不宣称全部可删。
