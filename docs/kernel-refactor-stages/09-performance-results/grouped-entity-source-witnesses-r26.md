The positive-hit reproduction created a Jan expense with one genuine source. A forged December `entity_reference_current.period` made `find_entities(used_from='2026-12')` return it and label it December; a damaged digest was likewise returned without error. Full integrity rejected the damaged index. The fix authenticates the latest winner and all same-period ties, including candidates that `used_to` would exclude and candidates beyond the response limit. It does not read unrelated name/kind candidates, old non-winners, or the full reference table.
