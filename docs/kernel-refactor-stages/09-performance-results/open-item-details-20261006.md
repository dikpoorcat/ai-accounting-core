# 待收、待付业务详情与刷新验证

## 展示与读取

待收、待付保留列表内展开，先说明对象、事项、已记录用途和业务所属月份，再突出选中款项的月末剩余金额，分别展示原应收／应付、实际收付以及抵销、代付等金额。供应商预付款使用尚未冲抵、已冲抵和已退回，不称为待收现金。历史余额和后续结清分别展示，未知金额保留待核对；未匹配到选中义务时保留列表明确金额，不套用整笔业务或其他义务。

下方“这笔业务的相关收付”明确包含整笔业务的其他款项，每条显示月份、用途、处理方式及金额；工资、奖金、劳务、个税和社保分别表达，更正不描述为重新付款。其他业务详情入口保留原布局，收付方式统一识别实际的 payment、offset、advance、accepted。

沿用业务详情合同6与现有生成校验，不修改公共接口、核算逻辑或数据库结构。列表只补传选中义务键、分类、状态和截止月份；金额继续由服务端提供，以整数分字符串和 BigInt 展示。详情展开才读取，每页20条，同快照再次展开复用已读结果；公司、月份、义务或快照改变时取消旧请求，待收待付收起失效详情，不自动读取另一版本。

真实浏览器发现原有可选 expanded 布尔属性被 Vue 默认置为 false，阻止了原生详情展开后的读取；已显式设默认 undefined，保留受控业务行的展开行为。脚本抽取式单元夹具未模拟这一框架默认值，实际浏览器展开验证负责覆盖。
