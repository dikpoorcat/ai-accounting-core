测量曾暴露主体筛选前遍历历史凭证、项目余额先扫描全域 effects 等残留，已在共享选取器与账户候选处收窄；前后检查点完整保留。新旧凭证选取器另有 48 组完整返回行差分一致证据，包含冻结、无影响复核、跨年冲正、当前头及过滤组合。

VM 通过间隔 100 的 progress handler 估算；不是精确单条 SQL 指令计时。Python 峰值含测量开销，不含 SQLite 原生内存或 OS 缓存；连接设置峰值另记于原始记录。本测量不代表机器冷启动或所有真实规模。

资金历史余额与投资成本确实依赖相关历史 effects，其 SQL 聚合仍随真实输入增长。准确领域汇总、相关义务、单个不可变大批次和完整采用图仍有相应输入／输出成本，不能截断为常数。
