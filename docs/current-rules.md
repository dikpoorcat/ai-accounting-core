# 当前保留规则

本文件是项目当前有效规则的简明入口。除仓库根目录 `AGENTS.md`、本文件和用户当前明确指令外，其他开发计划、验收记录、DEC 决策和历史资料均不自动生效。

## 协作

- 用户一步一指挥；完成当前步骤后停止。
- 默认不使用多 Agent，不自动推进路线图、下一模块或历史待办。
- 未经明确要求，不提交、推送、部署、迁移持久数据库或导入真实业务数据。

## 记账内核

- 公共入口只接收类型化业务事实，不接收任意科目、借贷方向或自由分录行。
- 入账金额使用整数分；税率和税额计算使用 `Decimal`，不使用二进制浮点数。
- 正式凭证必须借贷平衡；正式写入保持原子性和幂等性。
- 已过账凭证不原地修改；更正创建关联冲正凭证。
- 缺少会改变会计处理的事实时返回 `needs_information`，不采用推断性默认值。
- 税收规则按生效日期版本化，并记录首要官方来源 URL。

## 当前定位

- 当前是单企业私有试用阶段的确定性记账内核，不宣称是法定账簿、纳税申报或报税系统。
- 具体模块范围和现有接口以代码及 README 的能力说明为准；它们是当前实现状态，不是不可更改的永久产品决定。
- 验证范围按当前任务和风险选择，不设每次改动必须执行的固定全量测试矩阵。

## 数据库基线

- 当前确认不存在用户和历史业务数据库；Alembic 只保留面向空数据库的 `0001_baseline`。
- 不支持从已删除的旧 revision 原地升级。若以后发现历史库，先停止迁移并由用户另行决定处理方式。
